Parcel extensions

Value interpolation
<strong>{{this.value}}</strong> will be interpolated to: <strong><span nb-value="this.value"></span></strong>
Reserved file names
  • Reserved for main application html entry point
    • index.htm, index.html, index.xhtml
    • app.htm, app.html, app.xhtml
  • Reserved for main application styles entry point
    • index.styl, index.stylus, index.sass, index.scss, index.less, index.css, index.pcss, index.sss
    • app.styl, app.stylus, app.sass, app.scss, app.less, app.css, app.pcss, app.sss
Named pipe ref:
Force file include as a reference and not inline it <link rel="stylesheet" href="ref:animate.min.css"> <script type="module" src="ref:animate.min.js"></script>
