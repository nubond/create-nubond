Integrations

External tools integrations

• Both @nubond/showcase-app and @nubond/template-app use Parcel as their build tool

• Default Parcel behavior is slightly tuned for ease of use, via custom configuration (.parcelrc) and a custom PostHTML plugin (.posthtmlrc)

Parcel integrations

HTML | HTML import

Containers and Components HTML import
import html from './integrations.html';

@Container(html) or @Component(html) The imported value is preprocessed and ready to use as an HTML template

CSS | CSS import

Components CSS import
import css from './html-css-from-files.scss';

@Component(html, css) The imported value is preprocessed and ready to use as CSS

Naming conventions | file naming conventions

Reserved file names
  • Reserved for the main application HTML entry point
    • index.htm, index.html, index.xhtml
    • app.htm, app.html, app.xhtml
  • Reserved for the main application styles entry point
    • index.styl, index.stylus, index.sass, index.scss, index.less, index.css, index.pcss, index.sss
    • app.styl, app.stylus, app.sass, app.scss, app.less, app.css, app.pcss, app.sss

ref: | Named pipe

Force Parcel to include the file as a reference instead of inlining it
<link rel="stylesheet" href="ref:animate.min.css">
<script type="module" src="ref:animate.min.js"></script> Useful when external files must be included as a reference

{{}} | Text interpolation

Text interpolation using @nubond/posthtml-value-interpolation package
{{this.interpolated}}

will be interpolated to:
<span nb-value="this.interpolated"></span> Interpolated value: {{this.interpolated}}
