@AppRoot application entry point decorator
function AppRoot(...appBootstrapMetaData: Array<string | Element | IContextConfig | IGlobalConfig | IEntityDependencyConstructor>) {
} Parameters:
...appBootstrapMetaData: Array<string | Element | IContextConfig | IGlobalConfig | IEntityDependencyConstructor>
• string: app root element selector
Example: 'body' • string: app route template
Example: '/#[tab=basics]' • Element: app root element
Example: document.body • IContextConfig: root context (decorated class) configuration
IContextConfig interface: interface IContextConfig {
  //context-specific change detection strategy. By default global change detection strategy value will be used, if configured. Default value: false.
  pessimisticChangeDetectionStrategy?: boolean;
  //context-specific htmlSanitizer. By default global htmlSanitizer value will be used, if configured
  htmlSanitizer?: (html: string) => string;
} Example: {
  pessimisticChangeDetectionStrategy: true,
  htmlSanitizer: html => html
} • IGlobalConfig: global configuration
IGlobalConfig interface: interface IGlobalConfig {
  //Show debug info or not. Default value: false.
  showDebugInfo?: boolean;
  //If true all nuBond attributes should start from data-xxx prefix and use '-' instead of ':' in handler like nb-event:xxx, nb-attr:xxx, nb-prop:xxx, nb-aspect:xxx. Default value: false.
  complyWithW3C?: boolean;
  //Default global change detection strategy value. Default value: false.
  pessimisticChangeDetectionStrategy?: boolean;
  //Default global htmlSanitizer value. Default value: undefined.
  htmlSanitizer?: (html: string) => string;
  //Default global styleSanitizer value. Default value: undefined.
  styleSanitizer?: (style: string) => string;
} Example: {
  showDebugInfo: true,
  complyWithW3C: true,
  pessimisticChangeDetectionStrategy: true,
  htmlSanitizer: html => html,
  styleSanitizer: style => style,
} • Array<string>: $Template or $AdoptedStyle registration
Example: [$Template('my-template', html), $AdoptedStyle('my-style', style)] • IEntityDependencyConstructor: dependencies (containers, components, aspects, transformers or injectables) used globally or in application root
IEntityDependencyConstructor type: IContextConstructor | IComponentContextConstructor |
IAspectContextConstructor | ITransformerContextConstructor | IInjectableConstructor
IContext app root context interface
IContext interface: interface IContext {
  //Invoked when container is attached
  onContainerAttached?: (context: IContext) => void;
  //Invoked when container is detached

@AppRoot multi-app-roots
By design, there should be only one application root.
To simplify migration, nuBond supports a multiple-app-roots mode,
so that a page can be broken down into smaller chunks.
When nuBond is used in multiple-app-root mode, all registered entities are shared between all app roots.
When nuBond is used in multiple-app-root mode, global configuration and routing configuration must be set before any app root is registered.
This can be done using:
function $Config(config: IGlobalConfig) {
} Parameters:
• config: IGlobalConfig: global configuration
function $Route(routeConfig: string) {
} Parameters:
• routeConfig: string: route configuration
