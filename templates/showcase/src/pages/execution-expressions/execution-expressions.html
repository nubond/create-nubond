Execution Expressions

Associated with element handlers

• An expression is a small, valid JavaScript snippet (optionally prefixed with a flag) associated with a particular element handler

• Each expression has a this that points to the current execution context (the class context)

• Each expression has its own execution parameters that are available without this — they are injected as parameters

Execution expressions prefix flags

@ | constant expression flag

When there is a need to bind a constant value
nb-value="@Hello"

# | one time binding expression flag

When you need to bind a value once, as soon as it becomes available
nb-value="#this.value"

% | route slot constant expression flag

Router container expression extension
nb-container="%page" The container subscribes to a specific route slot to get the slot container name
Execution expressions in-element handlers

Base execution expression

Context is accessible by this
Example: nb-value="this.value"

Transformers are accessible by name
Example: nb-value="dateFormat(this.transformer)"

nb-repeat expression parameters

Repeat extends base execution expression parameters with
• index: number: current repeat index
• count: number: total number of repeat items
• item: any: current repeat item
Example: nb-value="`index: ${index}, value: ${item}, count: ${count}`"

Example: nb-value="`outer index: ${outerIndex}, index: ${index}`"
nb-value="`outer value: ${outerItem}, value: ${item}`"
nb-value="`outer count: ${outerCount}, count: ${count}`"





nb-bound expression parameters

Bound extends base execution expression parameters with
• element: Element: element that has been bound
Example: nb-bound="this.boundElement = nativeElement"

nb-event expression parameters

Event extends base execution expression parameters with
• element: ElementManipulations : element manipulations
• event: Event: event
• data: any: custom event data
• unSubscribe: () => void: unsubscribe function
• router: Router | undefined: the Router instance if one is configured
Example: nb-event:mouseover=
"element.styles.set('color', '#D9269D')"
nb-event:mouseout=
"element.styles.set('color', null)"
