Extenders

Various entities extenders

Templates

• Designed to enhance HTML templates with projections and HTML-based reuse

• Reducing duplication of HTML parts is a good use case for templates

Aspects

• Designed to adjust or extend the logic of an element

• Tooltips and form validation are good use cases for aspects

Transformers

• Designed to add custom functions to the expression execution context

• Filters, formatters and mappers are good use cases for transformers

• Transformers are singletons by design

@Detector property extender decorator

• Designed to automate change detection

• Can be applied to any configurable simple property

@Eventer property extender decorator

• Designed to automate CustomEvent dispatch

• Can be applied to any configurable simple property
