Containers

Swappable HTML templates with context

• Designed to be used as containers for HTML templates and components

• Automatic change detection happens only when input params change

• Have no dedicated styles — they reuse page styles

• An application page or a complex tab is a good use case for a container

nb-container HTML template with context
Continuous binding
nb-container="this.contType"

Single time binding
nb-container="#this.contType"

in & out input & output bindings
Continuous binding
nb-container="@InOut"
nb-in:input="this.inOutContainerInput"
nb-event:output="this.inOutContainerOutput = data"

IContext container context interface
IContext interface: interface IContext {
  //Invoked when container is attached
  onContainerAttached?: (context: IContext) => void;
  //Invoked when container is detached
  onContainerDetached?: (context: IContext) => void;
  //Invoked when all inputs are refreshed
  onInputsRefreshDone?: () => void;
  //Invoked when change detection is completed
  onDetectChangesDone?: () => void;

  onDispose?: () => void;
} Example: @Container(html)
