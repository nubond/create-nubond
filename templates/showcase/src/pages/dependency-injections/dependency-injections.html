Dependency Injections

Class-based dependency injections

• Dependency injection significantly simplifies application development

• Dependency injection can be used on any class marked with a special decorator

Dependency Injections regular dependency injections

@Injectable

 | 

injectable decorator

function Injectable(singleton: boolean = false) {
} Parameters:
singleton: boolean: true — this injection has only one instance; false — each injection creates a new instance
Registration example: @Injectable()
export class UserService {
} Dependency injection example: constructor(userService: UserService) {
  userService.registerUserLogin();
}

• ChangeDetector: bridge to request change detection
ChangeDetector class: class ChangeDetector {

  detect(): void;

  changeDetector.detect();
}

Element related

• ElementManipulations: element state manipulations
ElementManipulations class: class ElementManipulations {
  //manipulate element`s properties
  properties: {
    //get element`s property value
    get(propertyKey: string): any,
    //set element`s property value
    set(propertyKey: string, propertyValue: any): void
  },
  //manipulate element`s attributes
  attributes: {
    //check if element has attribute
    has(attributeName: string): boolean,
    //get element`s attribute value
    get(attributeName: string): string | undefined,
    //get all element`s attributes with values
    getAll(): Map<string, string | undefined>,
    //set element`s attribute value
    set(attributeName: string, attributeValue?: string | null): void,
    //remove element`s attribute
    remove(attributeName: string): void
  },
  //manipulate element`s styles
  styles: {
    //check if element has style
    has(propertyName: string): boolean,
    //get element`s style value
    get(propertyName: string): string | undefined,
    //get all element`s styles with values
    getAll(): Map<string, string>,
    //set element`s style value
    set(propertyName: string, propertyValue?: string | null): void,
    //remove element`s style
    remove(propertyName: string): void
  },
  //manipulate element`s classes
  classes: {
    //check if element has class
    has(className: string): boolean,
    //get all element`s classes with values
    getAll(): Array<string>,
    //add element`s class
    add(className: string): void,
    //remove element`s class
    remove(className: string): void,
    //toggle element`s class
    toggle(className: string): void
  }
} Example: constructor(elementManipulations: ElementManipulations) {
  elementManipulations.classes.add('ready');
}
Available in
• IComponentContext (@Component)
• IAspectContext (@Aspect)
• ElementSubscriptions: element events handling
ElementSubscriptions class: class ElementSubscriptions {
  //check if subscribed to an event
  isSubscribed(eventName: string): boolean;
  //check if unsubscribed from an event after a previous subscription
  isUnSubscribed(eventName: string): boolean;
  //subscribe to an event; returns an unsubscribe function
  subscribe(eventName: string, callBack: { (evt: Event): any }, options?: boolean | AddEventListenerOptions): (() => void);
} Example: constructor(elementSubscriptions: ElementSubscriptions) {
  elementSubscriptions.subscribe('click', evt => console.dir(evt));
}
Available in
• IComponentContext (@Component)
• IAspectContext (@Aspect)
