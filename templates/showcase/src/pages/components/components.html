Components

Reusable isolated components with context

• Web Components integrated into the framework

• Designed to be used as reusable, isolated components

• Automatic change detection happens only when input params change

• Always have an HTML template, can have styles — both are isolated by Web Components design

• A drop-down, date picker or button is a good use case for a component
