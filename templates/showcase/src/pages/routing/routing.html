Routing application state management

Route configuration

The route is configured in the @AppRoot decorator.
Config template: '/#[SLOT_NAME=DEFAULT_VALUE]/{SLOT_NAME=DEFAULT_VALUE}/CONST_VALUE' Details:
• /: route configuration flag. Mandatory.
• #: configures the Router to work against the hash portion of the location. Optional. If not provided, the router uses the path and search portions of the location
• CONST_VALUE, [SLOT_NAME=DEFAULT_VALUE], {SLOT_NAME=DEFAULT_VALUE}: slot configuration
   slot types:
   • []: container slot
   • {}: variable slot
   • CONST_VALUE: a constant string value slot — added to the route only if the preceding slot has a value
   • '[]' and '{}' slot configuration:
     • SLOT_NAME: slot name. Mandatory.
     • =: defines the slot's default value. Mandatory when a default value is needed.
     • DEFAULT_VALUE: default slot value. Optional.
• Multiple slots can be specified
• Slots are separated by the / flag
• The router is position-based: each slot value is placed at that slot's position whenever possible. If at least one slot without a value precedes a slot with a value, the slot with the value is moved to the search portion of the URL instead.
Examples:
Template: '/[page=dashboard]/{id}/{userId}/[container]'
Inputs: {
 page: 'dashboard',
 userId: 1
}
Route: '/dashboard/?userId=1'

Route container binding integration

To bind a container to a specific route slot:
nb-container="%SLOT_NAME" Details:
• %: route binding flag. Mandatory.
• SLOT_NAME: name of the configured slot. Mandatory.
Example:
nb-container="%page"

Route injection integration

Router can be injected into any class: import { Router } from 'nubond';
constructor(router: Router) {
}

Route expression execution context integration

Router can be accessed in any nb-event:xxx expression: nb-event:click="router.go('containers')"

Router class

class Router {
  //properties
  //is router configured
  isConfigured: boolean;
  //is the router hash-based
  hashBased: boolean;
  //current path
  path: string | undefined;
  //current state
  state: {[key: string]: string | undefined} | undefined;

  //methods
  //go to specific state
  go(state?: {[key: string]: string | number | null | undefined} | string, partialState = true, removeHistory = false): void;
  //go to previous state
  goBack(): void;
  //go to a specific state in history by index offset
  goTo(offset: number): void;
  //go to the next state
  goForward(): void;

  //events
  //subscribe to a BeforeStateChange event; returns an unsubscribe function
  onBeforeStateChange(callBack: (preventChange: () => void, oldState: {[key: string]: string | undefined}, newState: {[key: string]: string | undefined}, oldPath: string, newPath: string) => void): () => void;
  //subscribe to an AfterStateChange event; returns an unsubscribe function
  onAfterStateChange(callBack: (oldState: {[key: string]: string | undefined}, newState: {[key: string]: string | undefined}, oldPath: string, newPath: string) => void): () => void;
}
